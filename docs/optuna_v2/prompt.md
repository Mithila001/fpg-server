### Feature 1: Floor Plan Zones & Room Zoning Score
To analyze the floor plan, we overlay a 3x3 coordinate grid across the boundary. This divides the space into 9 distinct "zones", mapped using an (x, y) coordinate system where the bottom-left corner is the origin `(1, 1)`. 
*   The first digit `(x)` is the Column (Left to Right).
*   The second digit `(y)` is the Row (Bottom to Top).

*Grid Layout:*
*   Row 3 (Top): `(1, 3)`, `(2, 3)`, `(3, 3)`
*   Row 2 (Middle): `(1, 2)`, `(2, 2)`, `(3, 2)`
*   Row 1 (Bottom): `(1, 1)`, `(2, 1)`, `(3, 1)`

*Zone Ranges:* When defining ranges, we use `(x1, y1) - (x2, y2)` to create a rectangular selection of cells (e.g., `(1, 1) - (3, 1)` selects the full bottom row).

**Task:** Evaluate the room coordinates and calculate the **Room Zoning Score** based on the following rules:
*   Veranda: Must be within `1,1 - 3,1`.
*   Garage: Must be in `1,1` OR `3,1`.
*   Kitchen: Must NOT be within `1,1 - 3,1` AND must be in `2,2`.
*   Hallway: Must NOT be within `1,1 - 3,1`.
*   Living Room: Within `1,1 - 3,2` -> Give a score.
*   Bathrooms: ALL bathrooms must NOT be in `1,1 - 3,1` AND `2,2` -> Give a score.

### Feature 2: Room Outer Clearance Evaluations (Hard Score)
Some rooms require an outer wall to be exposed to the land. Take the target room point, define a bounding box based on its "Should Clear Direction", and score it if the box is clear (i.e., no other room points inside it).

*Clearance Box Definitions:*
*   **Back (y+):** Extends from `x-10` to `x+10` and up to `y+20`.
*   **Front (y-):** Extends from `x-10` to `x+10` and down to `y-20`.
*   **Left (x-):** Extends from `x-20` to `x` and between `y-10` and `y+10`.
*   **Right (x+):** Extends from `x` to `x+20` and between `y-10` and `y+10`.

**Task:** Perform this check for the following:
*   Veranda: Check if the "Front" side is clear.
*   Garage: Check if the "Front" side is clear.
*   Kitchen OR Hallway: Check if Kitchen's "Back", "Left", OR "Right" side is clear, OR if Hallway's "Back" side is clear.

### Feature 3: Room Relation Integrity Score
Using the Optuna sampled points, build a graph using `NetworkX` (which is already installed).

**Task 1: Build the Graph**
Hardcode the following relations and costs into the project file:
```json
[
  {"rooms": ["kitchen", "hallway"], "cost": 1},
  {"rooms": ["kitchen", "diningRoom"], "cost": 0.5},
  {"rooms": ["livingRoom", "kitchen"], "cost": 1},
  {"rooms": ["livingRoom", "hallway"], "cost": 1},
  {"rooms": ["livingRoom", "veranda"], "cost": 0.5},
  {"rooms": ["livingRoom", "bedroom"], "cost": 2},
  {"rooms": ["bedroom", "hallway"], "cost": 0.5},
  {"rooms": ["bedroom", "attachedBathroom"], "cost": 0.5}
]
```
Connect nodes based on these relations and apply the cost to the edge. 
*Multiple instances rule:* If there are multiple rooms of the same type (e.g., 2 bedrooms), connect *both* to the target node (e.g., connect both to livingRoom).
*Special case:* For `["bedroom", "attachedBathroom"]`, connect the attachedBathroom *only* to its closest bedroom.

**Task 2: Path Calculations**
Run the following path calculations:
```json
[
  {"start": "veranda", "end": "livingRoom"},
  {"start": "livingRoom", "end": "bedroom"},
  {"start": "livingRoom", "end": "kitchen"},
  {"start": "livingRoom", "end": "diningRoom"},
  {"start": "livingRoom", "end": "bathroom"},

  {"start": "bedroom", "end": "attachedBathroom"}

```
*Multiple instances rule:* Run paths for all instances separately (e.g., livingRoom to bedroom 1, and livingRoom to bedroom 2).
*Cost Formula:* Consider the physical distance (`x`) between points. Total travel cost = `x + (x * edge_cost)`. (Note: A higher cost means a lower score).
