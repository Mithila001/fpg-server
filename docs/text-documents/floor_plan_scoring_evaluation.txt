Floor Plan Scoring Evaluation
=============================

This document explains how a floor plan layout is evaluated in the solver. It describes the main checks and score components used to judge whether a layout is valid and how well it performs.

1. Hard validation checks
-------------------------
These checks are gatekeepers. If any hard validation fails, the layout is considered invalid and the final score becomes zero.

- Room geometry: Every room must have a positive width and height, the coordinates must be consistent, and rooms must lie inside the defined floor boundaries.
- No overlap: Rooms must not overlap each other. Any positive-area overlap between rooms makes the layout invalid.
- Adjacency rules: Required relationships between room types must be satisfied. For example, certain room types must touch or be adjacent to specific other rooms.
- Envelope/staircase bounds: If enabled, exterior-facing rooms must follow the allowed setback and facade gap rules on the selected sides.
- Empty space validation: The room shapes are combined into a single floor area shape. Any enclosed air gap inside the layout is treated as a validation failure.

2. Geometric gate
-----------------
After hard validation passes, one more geometric gate still applies.

- Inward pockets: The combined shape of all rooms is compared against its convex hull. If the layout contains a deep inward pocket segment that exceeds the allowed threshold, the layout is still considered technically valid, but it receives a minimal score of 1.

3. Main scored metrics
----------------------
If the layout passes both the hard checks and the inward-pocket gate, the final score is computed from three main components.

- Coverage: Measures how much of the floor area is filled by rooms. A layout that uses more of the available floor area scores higher, subject to a target minimum coverage.
- Rectangularity: Measures how closely the room cluster fits inside a compact bounding rectangle. A layout that avoids irregular empty holes around the rooms scores higher.
- Empty space: Rewards layouts with no enclosed gaps inside the combined room shape. If enclosed empty space is found, this score is set to zero.

4. Score weighting
------------------
The final score is a weighted combination of the three scored metrics.

- Coverage typically carries the largest weight.
- Rectangularity also carries a significant weight.
- Empty space is important and is included as a separate weighted component.

The score is usually expressed on a scale where 100 is very good for each metric, and the weighted sum becomes the final score.

5. Validity and final outcome
-----------------------------
- If any hard validation fails, the final score is 0 and the layout is invalid.
- If the layout has a deep inward pocket violation, it is still marked valid but receives a very low score (1).
- If the layout passes all checks, it receives a blended final score based on coverage, rectangularity, and empty space.

Key takeaway
------------
The evaluation is designed to first reject infeasible or broken layouts, then reward layouts that use space well, keep a compact shape, and avoid hidden gaps.
