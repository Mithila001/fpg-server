# Introduction

## 1.1 Overview

The project involved the development of an automated backend system designed for residential floor plan generation. The primary goal was to bridge the existing gap between a client's initial housing vision and the complex regulatory requirements mandated by architectural standards and local government laws. By utilizing a solver-driven generation pipeline, the system translates abstract room requirements and geometric limits into a valid, structured floor plan. Unlike standard AI floor plan generators that often prioritize aesthetics over accuracy, this system was engineered to treat building regulations as hard constraints to ensure real-world feasibility.

### Problem Statement

A significant disconnect frequently occurs when private landowners in Sri Lanka attempt to design house floor plans. Initial sketches produced by clients often fail to account for mandatory setbacks, spatial allowances, and minimum room dimensions required by the Urban Development Authority (UDA). Consequently, professional architects must heavily modify these initial concepts, leading to a cycle of costly and time-consuming revisions. Furthermore, existing automated solutions typically fail to validate against essential building codes or strict user-provided dimensions, rendering their outputs impractical for professional use.

### Proposed Solution

To address these inefficiencies, a digital intermediary tool was developed to empower landowners before their initial architectural consultation. The system utilizes a multi-stage pipeline:

- **Constraint Solving:** A core engine using Google OR-Tools CP-SAT to find feasible room arrangements within a buildable boundary.
- **Geometric Refinement:** A post-processing layer that cleans geometry, aligns rooms to a grid, and adjusts specific spaces like verandas using the Shapely library.
- **Opening Generation:** A specialized layer for the automated placement of internal doors, windows, and exterior exposure points.

## 1.2 Background

In the Sri Lankan residential design context, adherence to national building regulations and municipal zoning rules is a non-negotiable requirement for project approval. These regulations govern aspects such as maximum buildable area, ventilation, and passage clearances. Traditionally, verifying compliance is a manual, iterative process. This project was situated within this context to provide a "digital filter" that automates the translation of personal requirements into a regulatorily plausible blueprint.

## 1.3 Objectives

The project aimed to achieve several specific technical and functional goals:

- **Web-Based Interface:** The development of a responsive interface to allow for the straightforward input of land dimensions and programmatic needs.
- **Legal Space Calculation:** The implementation of a module to accurately determine the maximum buildable footprint based on dynamic setback and zoning regulations.
- **Constraint-Based Generation:** The integration of a Floor Plan Generation Algorithm capable of producing optimized layouts that meet functional needs, such as required room counts and minimum areas.
- **Regulatory Adherence:** To ensure all generated outputs strictly followed fundamental Sri Lankan building regulations, specifically regarding ventilation and room sizes.
- **Constraint Modification:** The provision of an interface allowing users to adjust non-fixed parameters to accommodate variations in local city development plans.

## 1.4 Deliverables

The following primary deliverables were produced as part of the project:

- **The Backend API (fpg-server):** A Python-based server implementing the generation pipeline and geometric post-processing.
- **Regulatory Profiles:** A library of configurable municipal rule sets that can be modified without deep alterations to the core codebase.
- **Export Functionality:** The ability to export the finalized structured floor plans and raw coordinates for downstream architectural use.

## 2.4 Scope and Limitations

The project scope was intentionally focused on single-story residential buildings to ensure the reliability of the core constraint logic.

- **Included:** Support for convex polygon land parcels, 2D floor plan visualization, and automated window/door placement.
- **Excluded:** Multi-story structures, detailed electrical/plumbing layouts, and advanced structural analysis.
